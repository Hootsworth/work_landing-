Open by default.Closed on purpose.

Most of what we build is open source under the Apache License 2.0. Some of it isn’t. Here’s how we think about that, and what we promise either way.

Read the missionSee the projects

Software you rely on should be software you can read. So most of ours is open source, with the code on GitHub for anyone to read, run, change and ship.

Use it

Apache 2.0 lets you use, change and distribute our code, commercially or not, and it carries an explicit patent grant.

Read it

Check what a tool does before you let it near your network, your files or your agents. The code is right there.

Fork it

If we vanish, or you disagree with us, the code is still yours to carry on.

How we decide.

Open by default.If there’s no good reason to close something, it ships open.
Closed needs a reason.One we’re willing to stand behind, not just a preference.
Honest labels.Every project says which it is. Nothing is quietly either.
Same standards.Closed or open: one job each, quiet by default, local-first where we can.

Take part.

Open an issue

Found a bug or want a feature? Say what you did, what you expected and what happened. Each open repo has an issue tracker.

Send a pull request

Fork, branch, add tests when behaviour changes, and explain your reasoning in the description. Check each repo for its contributing notes.

Just use it

Real use is the best contribution. Tell us what broke and what felt slow.

Read the code.

Everything open lives on GitHub. If you’re not sure whether a project is open, its page says so.
