Turn anywebsite intoan SDK.

Shiny Fishstick crawls a site once, discovers what it can do, and compiles it into a typed, agent-ready SDK. No selectors, no raw HTML, and no browser at all where a direct API call will do.

Every AI browser agent hits the same wall. It parses thousands of tokens of HTML to find a button, guesses selectors that break on the next refactor, and pays a context tax on every click. This isn’t a browser problem. It’s an abstraction problem.

Compile once. Call forever.

From URL to SDK in six stages.

  1. 1CrawlerBreadth-first traversal that handles auth redirects and session state.
  2. 2DOM AnalyzerScores selectors by stability: data-testid first, then id, class, and xpath.
  3. 3Intent EngineAn LLM or heuristic classifier maps elements to semantic actions.
  4. 4API SnifferWatches XHR and fetch traffic and upgrades UI actions to direct API calls.
  5. 5Workflow BuilderModels multi-step action sequences as a finite state machine.
  6. 6CompilerGenerates preflight.yaml, the SDKs and an MCP server.

OpenAPI, for sites that never had an API.

The output is a human-readable, version-controllable action spec. Once add_to_cart is discovered as a POST call, future runs skip the browser entirely.

preflight.yaml
actions: login: action_type: browser selector: '#login-form' add_to_cart: description: Adds a product to the cart action_type: api # upgraded to a direct API call api: url: /api/cart/add method: POST

Where it sits next to everything else.

Playwright is a great browser control library. Shiny Fishstick sits on top of it to add a compilation and abstraction layer.
