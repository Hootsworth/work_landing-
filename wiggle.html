Production Features.

🪄

Live DOM Rewrite & Hallucination

Toggle AI Mode, click any text, button, or paragraph on a website and ask Wiggle to rewrite it. Wiggle instantly regenerates the text and visually "wooshes" it into the actual webpage using a beautiful injection animation. Use /inject to build completely new UI elements directly into live pages.

/rewrite tone: professional
👻

Ghost Auto-Fill

Tired of job applications? Toggle AI Mode, type /autofill, and watch as Wiggle cross-references your Long-Term Memory Profile to invisibly "ghost type" into dozens of input fields simultaneously.

🎯

Sniper Vision Agent

Hit Cmd+K. Wiggle utilizes "Set-of-Mark" visual prompting, overlaying physical red badges on interactive elements, taking a snapshot, and deciding exactly what to click with 100% pixel-perfect precision.

🎓

Teach Mode

Train the Wiggle Agent. Perform a sequence of complex clicks and save it as a Skill. Later, type /run [Skill], and Wiggle will autonomously execute those actions for you.

🕷️

Swarm Web Research

Type /research [topic]. Wiggle silently deploys background Swarm Agents that bypass CORS, rip data directly from live search results, and synthesize a master research document inside your chat panel in seconds.

💻

Local Code Sandbox

Type /code [problem]. Wiggle writes the raw algorithm, securely executes it in an isolated local sandbox, and gives you the math/data results instantly.

📺

YouTube Interceptor

On any video, type /chatvideo. Wiggle instantly bypasses the UI, intercepts the hidden subtitle XML data directly from YouTube's server, and lets you chat with a 3-hour long video instantly.

🧠

Semantic Memory

Wiggle secretly indexes every webpage you visit entirely offline. Type /history [concept] to perform a neural search over everything you have ever read.

How to Deploy.

bash — wiggle-setup.sh
# 1. Install the Extension manually
  • Open chrome://extensions in Chrome.
  • Enable Developer mode (top right).
  • Click Load unpacked and select the Wiggle folder.
# 2. Add your Brain
  • Click the Wiggle icon in your toolbar.
  • Securely paste your Gemini API key.
# 3. Engage Commands
Cmd + Shift + L : Activate AI Selection Mode. Click elements or type /autofill.
Cmd + K : Deploy the Autonomous Agent (Sniper Vision).
